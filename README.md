# dan-bowie-florida

Bowie's weekend schedule and house notes for Dan, as a simple mobile web page.

It's a single `index.html` file with no build step and no dependencies.

## Publish with GitHub Pages

1. Push `index.html` to the `main` branch of this repo.
2. On GitHub, go to **Settings → Pages**.
3. Under **Build and deployment**, set Source to **Deploy from a branch**, pick `main` and `/ (root)`, then click **Save**.
4. After a minute or so the site will be live at `https://<your-username>.github.io/dan-bowie-florida/`.

## Editing

All content lives in `index.html`. Edit the text, commit and push, and Pages will update automatically.
